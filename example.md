# What you get

- VitePress style: Inter, indigo brand, `#bd34fe → #41d1ff` gradient hero
- Dark-first, with a complete light palette
- Layouts: `cover`, `intro`, `section`, `quote`, `statement`, `fact`, `end`
- `<Badge>` like in the docs:
  <Badge type="tip">tip</Badge>
  <Badge type="warning">warning</Badge>
  <Badge type="danger">danger</Badge>
  <Badge type="info">info</Badge>

Inline `code`, [links](https://9aia.com), and more.

```ts
// code blocks look like the docs
export function greet(name: string) {
  return `Hello, ${name}!`
}
```

> Blockquotes get the VitePress divider style.
